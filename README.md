- **[⌨️ 조작 3키로 단순화]** 이동(←/→) · 공격(Z) · 회피/패링(X) 만 쓰면 됩니다. 없앤 스킬 키는 공격 연격에 합쳤습니다 — 3연격 뒤 같은 버튼으로 **질풍참**, 이어서 **회천검무**(EX 20 소모). 초궁극기는 C. 터치에서는 ◀ ▶ · 수비 · EX · 공격 다섯 버튼뿐이고, 한 번 톡 누르는 것만으로도 이동합니다(길게 누르기 없이 가능).
