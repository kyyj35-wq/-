## ♿ 보이스오버 · 센스리더 접근성 (모든 게임 공통)

- 모든 게임은 **`#sr-announcer`(aria-live="assertive") 낭독 영역**으로 진행 상황을 소리로 전합니다.
- 스피릿 최강자들: 설정에서 **모바일(보이스오버) / PC(센스리더) / 자동 감지 모드** 분리 지원. 배틀 단축키 1~4 · M · A · S · C · T, Alt+1~8 전역 이동.
- 스피릿 로그: 1~4 기술 · B 포획 · P 회복 · S 교체 · C 상태 요약.
- 운빨 디펜스: Space/1 소환 · M/2 합성 · U/3 강화 · **T 초월 융합** · C 상태 요약.
- 미드나잇 서바이벌: 현재 상황 듣기 버튼 + 방향키/WASD/D-Pad.
- 모여봐요 우리 섬: 한국어 음성 낭독 토글 · 내 위치 및 주변 확인 버튼.
