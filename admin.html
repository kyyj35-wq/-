🟢 정상 운영 중

업데이트 배포 및 점검 시 유저 데이터 보호를 위해 전체 8대 게임의 서버를 일괄 잠그고 검은 화면에 점검 사유와 종료 시간을 큰 글씨로 안내합니다.
어드민 센터에서 원클릭으로 잠그거나 해제할 수 있으며, 개발자 전용 CLI 스크립트(`server_lock.py`)로도 동일하게 제어됩니다.

🟢 보안 검사 켜짐 (ON)

게임 접속 시 100개 보안 풀 코드 & 캔버스 음성 캡차의 출력 여부를 원클릭으로 제어합니다.
• 보안 검사 켜기 (ON): AI 크롤러 및 봇 차단을 위해 모든 게임 입장 시 4자리 캡차 인증 게이트를 활성화합니다.
• 보안 검사 끄기 (OFF): 캡차 없이 게임 화면으로 즉시 진입하여 빠른 테스트와 자유로운 플레이가 가능합니다.
