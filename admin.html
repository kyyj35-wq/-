어드민 센터에서 원클릭으로 잠그거나 해제할 수 있으며, 개발자 전용 CLI 스크립트(`server_lock.py`)로도 동일하게 제어됩니다.

🛡️ 스피릿 3대 게임 보안 검사 (Captcha 게이트) ON/OFF 제어

🟢 보안 검사 켜짐 (ON)

게임 접속 시 100개 보안 풀 코드 & 캔버스 음성 캡차의 출력 여부를 원클릭으로 제어합니다.
• 보안 검사 켜기 (ON): AI 크롤러 및 봇 차단을 위해 모든 게임 입장 시 4자리 캡차 인증 게이트를 활성화합니다.
• 보안 검사 끄기 (OFF): 캡차 없이 게임 화면으로 즉시 진입하여 빠른 테스트와 자유로운 플레이가 가능합니다.

🎮 게임별 치트키 발송

CHEAT QUEUE

고른 계정이 다음에 그 게임을 열 때 딱 한 번 대기열을 읽어 그 게임 세이브에 바로 적용합니다(계속 물어보지 않아 클라우드 요청을 아낍니다).
• 계정 ID는 소문자로 맞춰 보관되고, 다른 계정의 세이브는 건드리지 않습니다.
• 다른 게임용 치트는 대기열에 남아 그 게임을 열 때 적용됩니다.
• 실사용자 본계정(kyyj35)에는 보내지 마세요. 테스트는 dev 계정으로 하면 됩니다.

기본값은 개발자 테스트 계정 dev 입니다.

🎛️ 게임별 치트키 ON/OFF 제어

LIVE TOGGLE

스위치를 켜고 끄면 바로 클라우드(spirit-cheats/toggles)에 저장됩니다.
• 효과는 적용 대상 계정으로 로그인했을 때만 나옵니다. 다른 계정과 게스트에게는 절대 적용되지 않습니다.
• 게임은 열 때 한 번만 이 상태를 읽습니다. 바꾼 뒤에는 그 게임을 새로 열어야 반영됩니다.
• 온라인 대전(듀얼 PvP)·온라인 협동전에 들어갈 때 「치트키 해제 확인」 팝업이 뜹니다. 예를 고르면 치트가 해제되고, 아니요를 고르면 켠 채로 진행됩니다.

전체 치트키 마스터 스위치
끄면 아래 개별 스위치가 켜져 있어도 게임에서 아무 효과도 나지 않습니다.
기본값 dev — 이 계정으로 로그인했을 때만 치트가 켜집니다.

🃏 매 턴 3장 드로우
