# 스피릿 듀얼 v1.5.0 — 5칸 존 · 50장 덱 · 신규 카드 · 직접 선택 (2026-11-24)

베타테스터 피드백 4건을 모두 반영했다. 배포본 `v1.5.0-DUEL`, 평문은 `games_backup/duel.html.bak`.

## 1. 몬스터 존 5칸 · 마법/함정 존 5칸
- 양 진영 모두 3칸 → **5칸**. 존 길이는 `ZONE_COUNT = 5` 하나로만 정하고, 렌더링·전투·특수 소환·AI·효과 탐색에 3으로 박혀 있던 반복문을 전부 이 상수로 바꿨다.
- CSS는 `grid-template-columns: repeat(5, minmax(0, 1fr))`. 430px 이하(390px 아이폰)에서는 칸 간격 3px·안쪽 여백 3px·카드 이름 글자를 8.5px로 줄여 다섯 칸이 한 줄에 들어간다.
- 각 슬롯의 `aria-label`(몬스터/마법·함정 존 + 번호 + 카드 이름 + 공·수·표시 형식)은 그대로 유지.
- PC 키보드 단축키 확장: `1~5` 내 몬스터, `6~9, 0` 내 마법·함정, `Shift+1~5` 상대 몬스터, `Shift+6~9, 0` 상대 마법·함정 (`e.code` 기준이라 한글 자판에서도 동일).

## 2. 덱 20~50장
- `DECK_MIN = 20`, `DECK_MAX = 50`. 같은 카드 3장 제한 유지.
- 덱 편집 화면·규칙 안내 문구를 "20~50장"으로 갱신하고, 덱 편집에 **「덱 50장까지 채우기」** 원터치 버튼을 추가했다(보유 카드에서 강한 순서로, 같은 카드 3장·보유 수량 한도 준수).
- 기존 세이브(30장 덱)와 AI 덱(20~30장)은 그대로 동작. 세이브 검증·복구 경로는 `DECK_MAX`만 보고 자른다.

## 4. 직접 선택 모달
자동(랜덤·왼쪽부터)으로 처리되던 것을 **플레이어가 목록에서 직접 고르는 모달**로 바꿨다. 고른 값은 행동 기록(`act.choices` / `act.tributes`)에 실려 온라인 대전 상대 화면에도 그대로 적용된다.

- **특수 소환 제물**: 1장·2장 제물 특수 소환 모두 「제물 선택」 모달이 뜬다. 남길 몬스터는 누르지 않고, 보낼 몬스터만 골라 묘지로 보낸다. (일반 소환 제물 선택과 같은 방식)
- **덱 서치/특수 소환(덱)**: 조건에 맞는 후보 목록 → 1장 선택. 고른 카드가 패로.
- **묘지 소생/회수**: 묘지 후보 목록 → 1장 선택(소생은 수비 표시로).
- **효과 대상**: 파괴·바운스·공격력 감소·마법/함정 파괴 → 상대 존 목록에서 선택. 2장 파괴(쌍둥이 번개)는 다중 선택 후 확정.
- **공격력·수비력 강화 마법**: 내 몬스터 존을 눌러 대상 지정(기존 장착 마법과 동일).
- **패 교환**: 덱으로 되돌릴 패 카드 선택.
- 함정 응답(감시의 눈 등)도 같은 모달을 쓴다. 취소하면 아무 행동도 하지 않는다.
- 후보가 없으면 그 단계는 건너뛰고, 선택값이 없거나 잘못되면(옛 기록·AI·손상) 예전과 같은 결정론적 기본값으로 처리한다 → PvP 두 화면이 절대 어긋나지 않는다.
- 자동 선택 주체(스토리·랭크 AI)는 `aiFillChoices`가 같은 형식으로 스스로 채운다(제물은 가장 약한 몬스터부터, 대상은 가장 센 적).
