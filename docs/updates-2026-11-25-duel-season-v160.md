# 스피릿 듀얼 v1.6.0 — 시즌 1 「결투의 서막」 (2026-11-25)

14일 주기 시즌제를 도입했습니다. 시즌 1은 **2026년 11월 25일 ~ 12월 8일**이고, 14일이 지나면
시즌 2가 자동으로 시작되면서 패스·미션·랭크가 새 시즌 것으로 바뀝습니다.

## 새로 생긴 것

### 🏆 시즌 메뉴
- 하단 내비게이션에 **🏆 시즌**을 더했습니다. 7칸이 되어도 390px 아이폰 세로 화면에서 한 줄에 들어갑니다.
- 홈 화면 위쪽에 시즌 카드(시즌 이름·D-day·패스 단계·받을 보상 수)를 두어, 들어오자마자 이번 시즌 상황이 보입니다.
- 시즌 화면은 **패스 / 미션 / 랭크** 세 탭입니다. 각 탭은 실제 `button` 요소에 `aria-pressed`와
  자세한 `aria-label`을 달았고, 화면 이동·수령 결과는 `srAnnounce`로 낭독합니다(보이스오버·센스리더).

### 🎟️ 시즌 패스 (30단계)
- 100 XP마다 1단계, 30단계까지 총 3,000 XP. 스토리·랭크·온라인 대전, 카드 소환, 미션 보상으로 XP가 쌓입니다.
- **무료 트랙**: 단계마다 다이아 60(5단계마다 120)·골드 100(5단계마다 300), 10·20단계 SSR 카드팩, 30단계 전설 카드팩.
- **프리미엄 트랙**: 다이아 **2,400개**(최강자들과 같은 기준)로 이번 시즌에 한 번 엽니다.
  1~30단계 모든 보상이 무료의 2배이고, 15·30단계에 카드팩이 더 붙습니다. 확인 창을 한 번 거쳐 구매합니다.
- 단계별 수령과 **시즌 패스 보상 모두 받기**(무료+프리미엄 일괄) 버튼을 제공합니다. 버튼 숫자는 패스 보상만 세고,
홈·내비의 '받을 보상'은 패스·미션·랭크 티어를 모두 합한 수입니다.

### 📋 시즌 미션
- **일간**(매일 00:00 KST 초기화): 듀얼 1판 · 스토리 1승 · 카드팩 1회 소환
- **주간**(시즌 안에서 7일마다): 듀얼 5판 · 온라인 대전 2승 · 카드 10장 획득
- **시즌**(14일 누적): 스토리 10승 · 특수 소환 5회 · 온라인 대전 5승
- 보상은 시즌 XP + 다이아/골드. 완료 전·중복 수령은 막습니다.

### 🏅 시즌 랭크 (브론즈 ~ 그랜드마스터)
