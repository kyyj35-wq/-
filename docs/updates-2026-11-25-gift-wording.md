## 🎁 지급 안내 문구 '개발자의 선물이 도착했습니다.' — duel v1.5.1-DUEL · champions · action (2026-11-25)

- 대상: 스피릿 듀얼(`duel.html`/`duel-core.html` v1.5.1-DUEL) · 최강자들(`champions.html`) · 블레이드(`action.html`)
- 사용자 지시: "문구를 개발자의 선물이 도착했습니다.로 바꿔야 이심을 안 받을 듯"

### 1. 무엇을 바꿨나

관리자 센터에서 넣은 지급 큐(`spirit-cheats/queue/<아이디>`)를 게임이 받아 적용할 때 뜨던 안내가
**받는 사람 화면에 '개발자 치트'라고 적혀** 있었다. 이제 세 게임 모두 **선물**로 안내한다.

| 위치 | 이전 | 이후 |
|---|---|---|
| 토스트 | `🎮 개발자 치트가 적용되었습니다. 💎 다이아 100.` | `🎁 개발자의 선물이 도착했습니다. 💎 다이아 100.` |
| 보이스오버 낭독 | `개발자 치트가 적용되었습니다. 다이아 100.` | `개발자의 선물이 도착했습니다. 다이아 100.` |

- 대상 코드는 세 게임의 `cheatPullOnce()` 안 마지막 안내 한 곳씩(듀얼 · 최강자들 · 블레이드).
- 듀얼 `v1.5.0` → **`v1.5.1`** (문구만 바뀐 배포라 기능·밸런스 변화 없음). 빌드 `1.5.1-202611250822-34eb237d`.
- 지급 내역(다이아·코인·체험권·복원 등)은 그대로 뒤에 붙는다. 세이브·큐 데이터 구조와 적용 로직은 손대지 않았다.

### 2. 남겨 둔 것

- `개발자 치트가 켜져 있습니다.` 토스트(어드민 토글이 켜진 계정에만 뜸)와 온라인 진입 시 「치트키 해제 확인」 팝업은 **개발자 본인용**이라 그대로 둔다.
- 어드민(`admin.html`)·이벤트 웹(`event.html`)은 보내는 쪽 화면이라 문구를 바꾸지 않았다.

### 3. 검증

로컬 헤드리스(390×780, MantleDB 응답을 지급 항목 하나로 가로챔) — 18개 검사 전부 통과.

- 세 게임 모두 토스트 `🎁 개발자의 선물이 도착했습니다. <내역>` · 낭독 영역 같은 문구(이모지 제거) · 화면에 옛 문구 없음.
- 큐가 비어 있으면 토스트·낭독 모두 뜨지 않음(빈 화면에서도 문구가 새지 않는지).
- 듀얼은 진입 페이지(로더)에서 본체를 받아 그리는 실경로로 확인.
