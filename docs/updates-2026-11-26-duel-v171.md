# 스피릿 듀얼 v1.7.1 — 시즌 보상 탭 표시 · 자동 이동 (2026-11-26 핫픽스)

"받을 보상 2개"라고 해서 눌렀는데 패스 탭만 열려 보상이 없는 것처럼 보이던 문제를 고쳤습니다.
빌드 `1.7.1`, 진입 페이지는 그대로 `duel.html`(로더) → `duel-core.html`(본체)입니다.

## 무엇이 문제였나
- 홈 시즌 카드의 숫자는 **패스 + 미션 + 랭크를 합친 값**인데, 버튼은 늘 **패스 탭**만 열었습니다.
- 시즌 화면 위쪽 탭(`패스` · `미션` · `랭크`)에는 어느 탭에 보상이 남았는지 표시가 없었습니다.
- 그래서 패스 탭에 보상이 없으면 "받을 게 없다"고 오해하게 됐습니다.

## 바뀐 것
- **탭마다 받을 보상 개수를 표시합니다** — `🎟️ 패스 · 1개`, `📋 미션 · 2개`, `🏅 랭크 · 1개`.
  화면 낭독용 이름도 `미션 탭, 받을 보상 2개`처럼 개수를 함께 읽습니다(0개면 `받을 보상 없음`).
- **홈 시즌 버튼이 보상이 남은 첫 탭을 열어 줍니다** — 패스 → 미션 → 랭크 순서이고,
  홈 카드에도 `받을 보상 3개 · 미션부터`처럼 어느 탭부터 열리는지 적었습니다.
  셋 다 0개면 패스 탭(모두 받았다는 안내가 있는 곳)이 열립니다.
- **패스 탭에 받을 보상이 없으면** `패스 보상은 모두 받았습니다 (미션 2개 · 랭크 1개 대기). 위쪽 탭에서 받을 수 있습니다.`
  라고 안내하고, **미션 탭 열기 / 랭크 탭 열기** 바로가기 버튼을 둡니다. 이때 비어 있던 '보상 모두 받기' 버튼은 숨깁니다.
- 패스 일괄 수령을 눌렀는데 받을 게 없을 때도 `다른 탭에 미션 2개 · 랭크 1개 남아 있습니다.`라고 알려 줍니다.

## 확인
- 로컬 E2E(390px, 게스트·임시 프로필): 홈 카드 → 미션 탭 자동 열림, 탭 개수 표시·낭독 이름,
  패스 탭 안내·바로가기, 미션 수령 후 탭·홈 카드 즉시 갱신, 탭 3개 한 줄 유지, 콘솔 에러 0건.
- 실유저 세이브(`kyyj35` · `moki` · `gral`)와 클라우드는 건드리지 않았습니다.
