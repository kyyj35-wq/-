# 스피릿 듀얼 v1.7.2 — 고대 파워업·각성 · 차원의 복제 상향 · 패스 카드 3장 (2026-11-27)

빌드 `1.7.2`, 진입 페이지는 그대로 `duel.html`(로더) → `duel-core.html`(본체)입니다.
카드 수는 171종 그대로이고, 시크릿 4종에 **각성**이라는 새 성장 축이 붙었습니다.

## 새로 생긴 것

### ⚡ 고대 파워 뽑기 — 카드팩 화면의 전용 뽑기
- **카드팩 화면 맨 위**에 일반 카드팩과 구분되는 전용 배너를 두었습니다(금색·무지개 테두리).
- 비용: **1회 다이아 500 / 골드 5,000 · 5회 다이아 2,250 / 골드 22,500**. 5회는 확인 창을 한 번 거칩니다.
- **꽝 없음** — 어떤 결과든 아래 중 하나가 나옵니다.

| 보상 | 확률 |
|---|---|
| ⚡ 고대 파워업 | 18% |
| 🔨 카드 조각 100 / 250 / 500 | 26% / 20% / 10% |
| 🪙 골드 3,000 | 14% |
| 💎 다이아 300 | 7% |
| 🌹 SSR 카드 1장 / 👑 전설 카드 1장 | 3.5% / 1.5% |

- **10회 천장**: 고대 파워업이 나오지 않은 채 9회를 채우면 다음 뽑기에서 확정으로 나옵니다.
  배너에 `다음 고대 파워업까지 N회`가 표시되고, 아이템이 나오면 천장이 처음부터 다시 쌓입니다.
- 풀은 `ANCIENT_GACHA_POOL` 표 하나로 정의했습니다 — **앞으로 고대 아이템·각성 소재는 표에 한 줄만 더하면**
  같은 뽑기에서 나옵니다. 아이템 정의는 `ANCIENT_ITEMS`, 각성 능력은 `AWAKEN` 표에 있습니다.
- 상점 단품 구매·제작 탭 직제작은 두지 않았습니다(이번 지시대로 획득처는 뽑기 하나).

### ⚡ 고대 파워업 → 시크릿 카드 각성
- 얻은 아이템은 **인벤토리**에 쌓이고, 인벤토리 맨 위 「⚡ 고대 파워업」 카드에서 **보유 시크릿 카드 1장에 영구 접착**합니다.
  이미 접착한 카드는 `각성 완료`로 표시되고 다시 붙일 수 없습니다.
- 접착하면 전용 연출·효과음과 함께 각성하고, 덱·도감·카드 상세·**배틀 필드**에 `⚡ 각성` 배지(금색 테두리)와
  각성 능력치·효과가 표시됩니다. 화면 낭독도 `고대 각성`을 함께 읽습니다.

| 카드 | 기본 → 각성 | 각성 능력 |
|---|---|---|
| 🧿 **영겁의 수호자** | 2900/3200 → **4000/4500** | 이 카드가 내 필드에 있는 동안 **내 생명점은 전투·효과 데미지를 받지 않음** · **턴당 2회까지 파괴 무효** · 내 턴 종료 시 **1장 드로우 + 상대 생명점 500** |
| ☄️ **일식의 불사조** | 2800/2300 → **4200/3500** | 소환 시 **상대 필드 카드 최대 2장 파괴(몬스터 우선)** + **내 묘지에서 레벨 제한 없이 2장 수비 특수 소환** · 파괴되면 **다음 내 턴 시작에 자동 부활** |
| 🔁 **차원의 복제** | — | 복제 발동에 더해 **2장 드로우 + 상대 몬스터 1장 파괴 + 내 LP 1000 회복** |
| 🪞 **업보의 거울** | 120% 반사 → | 공격 무효 + **상대 필드 몬스터 전부 파괴** + **공격력 250% 직격** + **2장 드로우 + 내 LP 1000 회복** |

- 각성 능력치는 카드 ID 표(`AWAKEN`)만으로 정해지고, 판에서는 진영별 목록(`B.awake`)으로 계산합니다.
  **온라인 대전은 방 설정(`awake`)에 양쪽 목록을 적어** 두 화면이 같은 능력치·효과로 판을 세웁니다
  (구버전 방처럼 목록이 없으면 각성을 적용하지 않아 판이 갈라지지 않습니다).

## 바뀐 것

### 🔁 차원의 복제 — 패에서 썩지 않게
1. 상대가 최근에 발동한 마법이 있으면 그대로 복제합니다(기존).
2. 없으면 **내 묘지·상대 묘지의 마법 1장을 골라**(모달, AI는 자동) 복제합니다.
3. 양쪽 모두 복제할 마법이 없으면 **카드 2장 드로우**로 대체 발동합니다.
- 복제 카드 자신은 복제 대상이 되지 않는 규칙은 그대로입니다.

### 👑 배틀 패스 프리미엄 30단계 — 전용 카드 1장 → 3장
- `계약의 군주 자하르`를 **3장** 지급합니다(덱 최대 사본 3장과 같게). 패스 UI·보상 문구도 `3장`으로 표시합니다.
- **기존 수령자 자동 보정**: 프리미엄 30단계를 이미 받았는데 3장 미만이면(한 장도 못 받은 경우 포함)
  접속·클라우드 세이브 적용 시 **3장까지 채워 주고** 한 번 안내합니다.

### 🃏 지급 큐 `add_card`
- `{ game:'duel', action:'add_card', cardId:'m_pactlord', amount:3 }` 형식으로 카드를 직접 지급합니다.
- 안내 문구는 `🎁 개발자의 선물이 도착했습니다. 🃏 계약의 군주 자하르 3장.`
- 배틀 패스 전용 카드는 **'적어도 amount 장'**(이미 3장이면 변화 없음)으로 처리해 중복 지급을 막습니다.
  다른 카드는 더하기 지급입니다(최대 99장).
