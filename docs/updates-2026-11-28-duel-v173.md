## 바뀐 것

### ❤️ 기본 생명점(LP) 4,000 → 20,000
- 엔진 상수 `LP_MAX = 20000`. 대전 시작 생명점·LP 최대치·LP바·회복 상한이 모두 이 값을 씁니다.
- 화면 문구도 전부 바꿨습니다 — 대전 상단 부제 `LP 20,000`, 양쪽 LP 초기 표시 `20000`,
  규칙 안내(`생명점(LP) 20,000`), 이그니펫 튜토리얼 첫 장.
- 카드 공격력/수비력(`atk:4000` 등)과 시즌 랭크 보상 골드(`gold:4000`)는 LP가 아니므로 그대로입니다.

### 🎛️ 개발자 치트 `godLp` 99,999 → 198,000
- 시작 생명점 `198,000`(최대치도 같이). 어드민 토글 이름·설명·`aria-label`, 게임 안 치트 목록·
  이벤트 안내 문구 모두 `198,000`으로 맞췄습니다.
- 생명점 값을 매직 넘버로 비교하던 자리를 **진영별 플래그 `B.godLp`** 로 바꿨습니다.
  (온라인 대전은 방 설정 `cheatRules`를 양쪽이 함께 읽어 두 화면의 값이 같습니다.)

### ❤️ 시작 라이프 체험권 +100 → +200 (기본 20,000 → 20,200)
- 저장 키 ID는 호환을 위해 **`trial_lp_100` 그대로** 두고 수치만 올렸습니다(옛 세이브·이벤트 서버 호환).
- 새 이름 `trial_lp_200` 으로 보내는 곳도 같은 체험권으로 인식합니다(`trialNormKey`·`sanitizeTrialRules`).
- 체험권 문구: `❤️ 시작 라이프 +200 7일 체험권` · `❤️ 라이프 +200`.

## 고친 잔버그

1. **일반 소환의 제물 목록 검증 누락** — `actSummon` 이 제물 인덱스를 중복·범위 검사 없이 그대로 썼습니다.
   `tributes:[0,0]` 처럼 같은 존을 두 번 보내면 제물 1장으로 ★7을 낼 수 있었고,
   `[0,99]` 같은 값도 통과했습니다. 특수 소환(`actSpecial`)과 같은 잠금(정수·존 범위·중복 제거)을 넣어
   조건을 못 채우면 소환 자체를 거부합니다.
2. **관통 데미지에 `battleReduce` 미적용** — 수비 표시 카드의 "받는 전투 데미지 N 감소"가 반사 데미지에는
   쓰이는데 관통 피해에는 쓰이지 않았습니다(값을 선언만 하고 쓰지 않던 자리). 카드 문구대로
   `관통 피해 = (공격력 - 수비력) - battleReduce` 가 되도록 고쳤습니다(최소 0).
3. **godLp/체험권 겹침 판정이 값 비교** — `lp !== 99999` 로 판정해 상수를 두 곳에서 관리해야 했습니다.
   진영 플래그 `B.godLp` 로 바꿔, 치트 값이 또 바뀌어도 체험권이 덮어쓰지 않습니다.

### 점검했지만 문제 없던 항목
- LP바 너비는 `clamp(lp / lpMax * 100, 0, 100)`, 회복은 `Math.min(lpMax, ...)` 이라
  20,200·198,000 상태에서도 100%를 넘거나 회복이 잘리지 않습니다(테스트로 확인).
- v1.6.0 시즌(패스·미션·랭크)·v1.7.0~1.7.2(인벤토리·시크릿·고대 파워 뽑기·각성·차원의 복제·소환/대상 선택)는
  기존 회귀 테스트(v1.7.2 엔진 47항목)와 무작위 자동 대전 12판에서 예외·불변식 위반 0건이었습니다.
