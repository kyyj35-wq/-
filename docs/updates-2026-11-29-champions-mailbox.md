# 스피릿 최강자들 📮 우편함 신설 — v4.6.1 (2026-11-29)

## 왜
시즌 3 「심연의 성역」 전환 확인이 늦어진 데 대한 지연 보상(`game-notes/지연-보상-규칙.md`: 기본 1,000 + 10분 지연 500 = **1,500 다이아**)을
받을 곳이 없었다. 앞으로 운영자가 전체 우편을 보낼 수 있는 자리를 만들고, 그 첫 우편으로 1,500 다이아를 지급한다.

사용자 지시: "그냥 아예 우편함을 만들자" (2026-11-29 00:11).

## 무엇이 바뀌었나
- **홈 카테고리**: `📮 보상 받기` → `📮 우편함`.
  - 카드 요약: `받을 우편 N통`, 배지 `우편 N`, 낭독은 "우편함 카테고리. 받지 않은 우편 N통이 있습니다. …"
- **우편함 화면**(`#screen-reward`, 화면 이름 '우편함'):
  - 머리말 카드(MAILBOX / 📮 우편함 / 미수령 안내)
  - `📬 받은 우편` 목록 — 우편마다 제목·보낸이·도착일·구분(전체 우편)·본문·보상 내역·`📬 보상 받기` 버튼, 수령한 우편은 `✓ 수령` + `✓ 수령 완료`
  - `📬 우편 N통 모두 받기`(미수령이 1통 이상일 때)
  - 기존 `📮 쿠폰 코드 입력`과 `🎏 콜라보 코드(SB26)` 안내는 그대로 유지
- **세이브**: `STATE.claimedMailIds`(문자열 배열)에 수령한 우편 id 기록. `defaultState()` 기본값 + `mailEnsure()` 보정으로 옛 세이브도 그대로 동작.
  계정별 세이브(`spirit_save_store_v1`)·클라우드 세이브에 함께 저장되므로 새로고침·재접속·계정 전환에도 중복 수령이 없다.
- **개발자 지급 큐와의 관계**: `spirit-cheats/queue/<id>` 선물은 지금처럼 '개발자의 선물'로 자동 도착한다.
  둘 다 `STATE` 재화에 더해지며 서로의 기록을 건드리지 않는다(테스트 확인).
- **접근성**: 우편 묶음 `role="group"` + 상세 `aria-label`(제목·보낸이·도착일·수령 여부·보상), 목록 `role="region"`, 수령 버튼 `aria-label`("… 우편 보상 받기, 다이아 1,500개"),
  수령 결과는 기존 라이브 리전(`#sr-announcer`, assertive)으로 낭독, 수령 후 초점은 받은 우편으로 복귀. PC 모드·390px 모두 확인.
- **온보딩**: '다음에 할 일'에 미수령 우편 안내 추가, 마스코트 도움말의 카테고리 목록을 '우편함'으로 수정.

## 새 우편을 넣는 법
`MAILBOX_DEFS`(champions.html.bak)에 항목을 추가하고 `compile_champions.py`로 다시 빌드한다.

```js
{ id: '고유id', icon: '🎁', tag: '전체 우편', title: '제목', from: '운영자', date: '2026-12-01',
  body: '본문', rewards: { gems: 1000, shards: 50, tickets: 1 } }
```
지원 보상 키: `gems`(다이아) · `shards`(강화조각) · `tickets`(소환권) · `megastones`(메가스톤) · `resonanceCores`(공명의 정수) · `s2tickets`(시즌 티켓).
